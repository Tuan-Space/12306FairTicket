# 🚄 12306 Fair Ticket

**把不同车站、车次和席别放进同一个购物车，按你的顺序尝试购票。**

## ✨ 核心功能

- 🛒 **多站点备选**：北京南 → 上海虹桥、北京 → 上海，可以一起加入；拖动购物车调整优先顺序，任意一项成功后整车停止。
- ⏰ **定时开抢**：设置日期、开售和停止时间，自动校时、检查登录，也支持立即开始或仅监控余票。
- 👥 **一起出行**：扫码读取乘车人，最多选择 5 人，每人可选默认、成人票或学生票。
- 💺 **位置偏好**：支持座位、上中下铺和静音车厢偏好，只作用于对应席别，不改变购物车中的车次或席别。
- 💾 **保存配置**：保存购物车与参数，下次导入继续使用；登录凭据不随配置保存。

> 🎯 购物车是**同一次出行的多个备选**，不是分别购买多段行程。位置偏好是否满足，以 12306 实际分配为准。

## 🚀 四步使用

### ① 🗺️ 设置行程

选好日期和时间，填写出发站、到达站、车次，勾选席别后点 **「加入购物车」**。点右下角 🛒 调整备选顺序，再进入下一步。

### ② 📱 登录与乘车人

点击 **「扫码登录 12306」**，用 12306 App 扫码确认。勾选乘车人并核对车票类型，也可以直接填写姓名。

### ③ ✅ 确认并开始

核对购物车、乘车人和时间，需要时设置位置偏好。**只有点击本页「开始任务」才会执行订票；登录和选择乘车人不会自动开始。**

### ④ ⏳ 等待结果

保持程序运行，查看倒计时、查询和订单结果。**成功后请到 12306 App 或官网核对并支付**；需要调整时停止任务、返回修改。

## 📦 下载与打开

1. 前往 **[下载 2.1.0 Windows 便携版](https://github.com/Tuan-Space/12306FairTicket/releases/tag/v2.1.0)**，下载 `12306FairTicket-2.1.0-windows-x64.zip`。
2. **完整解压**，双击 `12306FairTicket.exe`，无需安装 Python。
3. 请保留旁边的 **`_internal` 文件夹**，不要只复制 EXE。适用于 Windows 10/11 x64。

🔇 程序不弹系统通知、不播放声音，请留意窗口结果。若显示“结果待核对”，先到 12306 检查订单；停止程序不会撤销已生成的订单。
