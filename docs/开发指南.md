# 从 GitHub 恢复、开发与打包

仓库包含 GUI、CLI、订票逻辑、资源、内置站点快照、测试、依赖版本及构建脚本，不依赖原作者电脑的缓存或历史输出。需要 Windows 10/11 x64、Git、Python **3.12** 和可下载 Python 包的网络。

本地购物车预览尚未发布到 GitHub。复现这次改动请使用随预览包交付的源码 ZIP，或保留当前本地分支；GitHub main / 已发布 Release 仍是上次发布内容。

## 1. 重新下载并安装

在 PowerShell 中执行：

```powershell
git clone https://github.com/Tuan-Space/12306FairTicket.git
cd 12306FairTicket
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements/dev.txt
.\.venv\Scripts\python.exe -m pip check
```

无需激活环境，也不用设置全局 Python 包。`requirements/dev.txt` 包含运行、测试及打包依赖；`constraints.txt` 锁定直接和间接依赖的版本。如果只运行 GUI，可改用 `requirements/gui.txt`；仅 CLI 则用 `requirements/base.txt`。

也可以在 GitHub 的 **Code → Download ZIP** 下载 main，解压后从创建虚拟环境开始操作。继续修改建议用 `git clone`，保留提交历史。Release 下的源码包与对应版本标签是一份发布快照；继续开发请下载 main，历史标签不随整理改写。

## 2. 启动程序

```powershell
.\.venv\Scripts\python.exe gui.py
```

四步流程见 [操作说明](四步订票流程操作说明.md)。源码与 EXE 共用 `ticket_app`；没有另一份独立的 GUI 订票引擎。

CLI 用户先修改根目录 `config.py` 中的日期、站名、乘车人、席别和时间，再执行：

```powershell
.\.venv\Scripts\python.exe main.py --validate-config
.\.venv\Scripts\python.exe main.py
```

校验命令不会联网。GUI 不读取 `config.py`，通过界面导入／保存 JSON v5，并兼容 v1/v2/v3/v4。CLI 执行配置脚本，请只使用自己信任的配置文件。

CLI 可选填 `CART_ITEMS` 有序列表，每项包括 `from_station`、`to_station`、`train_scope`（`specific` / `all`）、`train_code`（不限车次时为空字符串）和 `seat_type`（一个中文席别名）。同一站对不同车次或席别各占一项。省略该字段或设为 `None` 时保留旧逻辑，显式空列表不允许启动。未使用购物车时还可设置 `PRIORITY_STRATEGY`（`train_first` / `seat_first`）、`EMPTY_TRAIN_SCOPE`（`high_speed` / `conventional` / `all`）、`PASSENGER_TICKET_TYPES`（姓名对应 `adult` / `student`）和 `QUIET_CARRIAGE_PREFERENCE`。参数注释位于 `config.py`。

## 3. 运行回归测试

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m pytest tests -q -p no:cacheprovider --basetemp .pytest-tmp-local
Remove-Item Env:QT_QPA_PLATFORM
```

测试覆盖配置、接口解析、候选排序、联系人与票种、偏好、GUI 鼠标／键盘、登录复查、停止重启及线程收尾。它们使用模拟接口，不真实登录或提交订单。保留这些测试是为了后续改动时发现回归；历史试验脚本和重复的测试输出不属于测试套件。`.pytest-tmp-local` 专用于测试临时数据，pytest 会重建这个目录，请勿放入自己的文件。

## 4. 构建 Windows EXE

```powershell
.\scripts\build_windows.ps1 -Python '.\.venv\Scripts\python.exe'
```

脚本先测试，再从 `scripts/12306FairTicket.spec` 构建，并检查 EXE 能正常启动退出。已单独通过测试时可加 `-SkipTests`。构建购物车预览并保留已有包时，使用 `-OutputRoot artifacts/cart-preview`。默认输出为：

```text
dist/12306FairTicket/
  12306FairTicket.exe
  _internal/
  README.md
  docs/
```

可用 scripts/verify_bundle.py EXE路径 --output 核验结果.json 比对打包代码与当前源码。整个目录可直接复制到其他 Windows x64 电脑。`_internal` 必须保留。锁定依赖可复现功能、版本和构建流程；不同 Windows/Python 补丁版本及构建时间可能影响 EXE 字节，不能据此承诺每次 SHA256 相同。

GitHub Actions 在 main 更新、PR、版本标签及手动触发时运行同样的安装、测试、打包流程。构建产物在 Actions 中短期保存，不自动创建 Release。

## 目录用途

| 路径 | 内容 |
| --- | --- |
| `gui.py` / `main.py` / `config.py` | GUI 入口、CLI 入口和 CLI 示例配置 |
| `ticket_app/` | 共享订票逻辑与 GUI |
| `assets/` | 程序运行所需的样式、图标和站点快照 |
| `tests/` | 有效回归测试 |
| `requirements/` | 运行／开发依赖与版本约束 |
| `scripts/` | Windows 构建配置、文档截图脚本 |
| `docs/` | 使用、开发、原理、更新记录及文档图片 |
| `.github/` | 自动测试和构建工作流 |

`.venv/`、`build/`、`dist/`、`artifacts/`、`.repro/`、Python 缓存和 `.runtime/` 都是本地生成数据，已忽略，不应提交。GUI 站点缓存与日志位于 `%LOCALAPPDATA%\12306FairTicket`；用户另行保存的 JSON 配置不属于源码备份。CLI 若显式启用会话持久化，`.runtime/` 可能含敏感数据，不要打包上传。

## 更新文档截图

```powershell
.\.venv\Scripts\python.exe scripts/capture_screenshots.py
```

脚本从实际 GUI 控件截取新版四步页面，禁用网络并使用示例联系人和等待状态，输出到 `docs/images/`。截图用于文档，不作为程序资源打进 `_internal`。

## 购物车界面检查

```powershell
.\.venv\Scripts\python.exe scripts/check_cart_layout.py
```

使用真实 Qt 窗口、模拟联系人检查深浅主题和 100%/150%/200% 缩放；输出截图与矩阵结果到 `artifacts/cart-ui-check/`。购物车功能与本次完整回归见 [购物车预览验证报告](购物车预览验证报告.md)。
