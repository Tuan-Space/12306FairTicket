## 功能回归覆盖

- 扫码与选择乘车人均不会启动订票；仅确认页开始或安全停止后的继续按钮创建任务。
- 常驻执行器串行处理操作，旧代次回调不影响新任务；关闭时工作对象迁回 GUI 线程后销毁。
- 第四步返回立即取消，收尾前只读；继续按原配置重新查询并复用有效会话。
- 确认请求已发出、成功或结果不明时禁止再次下单；异常订单响应不误判为可重试。
- 停止时间已过及跨午夜不会自动顺延；联系人读取失败保留有效登录。
- 两种候选排序、独立卧铺代码、逐人车票类型、偏好适用条件、配置兼容、脱敏日志和无系统提醒。

前一轮更详细的生命周期压力记录见 [四步订票流程第二轮验证报告](四步订票流程第二轮验证报告.md)；其中版本和本地交付说明仅反映当时的 1.1.1 预览包。本次发布另行生成 2.0.0 包，保留原本地包。
