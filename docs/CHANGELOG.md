## v2.0.0 — 2026-09-28

- 采用“设置行程 → 登录与乘车人 → 确认并开始 → 等待结果”四步流程，明确区分准备操作与订票任务。
- 登录后直接勾选乘车人，支持逐人选择成人票或学生票、联系人读取失败后手动填写，以及二等座静音车厢偏好。
- 保留开售前登录复查、最终校时和等待阶段手动辅助操作，重新登录后重新匹配乘车人。
- 第二步在账号区域直接扫码登录，去掉手动登录检查和重复提示；车票类型用默认、成人票、学生票说明，默认项显示 12306 乘客信息。
- 登录、联系人、校时和订票改由常驻工作对象串行执行；取消后丢弃旧结果，关闭时非阻塞收尾，Qt 对象统一按所属线程管理。
- 第四步支持立即返回确认页并取消；安全停止后可按原配置继续新一轮任务，查询计数归零、有效会话复用。
- 已提交确认请求、成功或结果不明时禁止重复下单；严格检查订单响应格式。停止时间不自动顺延到次日。
- 默认窗口 750×880 逻辑像素，详细日志固定在运行页正文下方并默认展开；日志文本不再驱动运行状态。
- JSON 保持 version 4，系统通知和提示音继续关闭。发布验证记录见 [v2.0.0 发布验证报告](v2.0.0发布验证报告.md)。
