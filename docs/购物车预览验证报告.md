# 多站点购物车预览验证

日期：2026-09-28。应用版本仍为 **2.0.0**，GUI 配置为 **JSON v5**。本次只交付本地源码与独立预览包，没有推送 GitHub、创建标签或修改 Release。

## 实现范围

- 第一页以“站对 + 指定单车次或不限车次 + 单席别”为一个备选，支持多车次拆项、重复检查和未加入草稿提醒。
- 购物车支持拖动、键盘、上下移动、单行编辑与删除；列表顺序即实际尝试顺序。确认页逐项展示，运行页展示当前项目与成功区间。
- 一个执行器、一个会话、一套订单安全状态。每轮按站对复用新查询，交错顺序不变；不限车次与明确车次重叠时按实际区间、列车与席别去重。
- 查询失败和无票分别显示；失败站对本轮跳过，下轮重试。请求及回退端点共享热身/常规限速，最大轮数按完整购物车轮询计算。
- 旧配置迁移保留不可等价排序的说明；无法表达的旧类型限制保持待修正，明确确认之前不能启动。CLI 不使用 `CART_ITEMS` 时保留原规则。
- 座位、五种卧铺与静音偏好仍按候选能力应用。继续任务使用原快照、新查询与新票据；成功、结果不明或已发出确认排队请求时禁止再次直接提交。
- 移除被购物车替代的旧席别选择控件及专属测试，保留偏好能力回归；文档截图均从实际控件离线生成。

## 额外修正：跨夜经停车的乘车日期

官方查询脚本把原始余票第 13 列命名为 `start_train_date`，提交表单使用页面选择的 `train_date`；确认页排队参数使用 `orderRequestDTO.train_date.time`。列车始发日可能早于旅客上车日，不能混用。

现在保留原始始发日并单独记录本次查询乘车日；提交用查询日期，排队前核对服务端订单日期。返回站码必须与查询站对一致，提交站名由核验后的标准站名确定。原始实时票据不写入配置、不跨轮复用。

核对来源：[12306 官方查询脚本](https://kyfw.12306.cn/otn/resources/merged/queryLeftTicket_end_js.js?scriptVersion=1.95051)、[12306 官方订单脚本](https://kyfw.12306.cn/otn/resources/merged/passengerInfo_js.js?scriptVersion=1.95053)。只读取公开脚本，没有登录或提交订单。
