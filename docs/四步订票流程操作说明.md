# 四步订票流程操作说明

**① 设置行程 → ② 登录并选择乘车人 → ③ 确认并开始 → ④ 等待结果**

首次准备时，前三页显示“任务未开始”。扫码登录、选择乘车人和校准时间都是准备操作；确认页点击“开始任务”才会执行，停止后点击“继续任务”会重新创建一轮任务。窗口默认大小为 750×880 逻辑像素，并根据屏幕可用空间调整；顶部步骤和底部操作保持可见，正文可以滚动。第 ④ 页的详细日志固定在窗口底部，默认展开，可随时收起。

## ① 设置行程

填写出发站、到达站、乘车日期、开售时间和停止时间。选择可接受的席别，并把已选席别拖到希望尝试的顺序；新打开程序时不会预选席别。

- 有优先车次时，按填写顺序尝试。勾选“只尝试上述车次”会限定清单；不勾选则允许其他车次备选。
- 优先车次留空时，不限列车类型，按所选席别筛选。
- “车次优先”先按车次，再按席别；“席别优先”先按席别，再按车次。页面会显示尝试顺序示例，实际运行跳过无票候选。
- 选择自动提交或仅监控。仅监控不会提交订单。

需要调整查询频率、热身、超时等参数时，展开高级参数。已有配置可通过顶部“导入…”恢复，也可用“保存为…”保存未填写完整的草稿。配置不会保存步骤进度或登录状态。

点击 **“下一步：登录与乘车人”**。若当前步骤有问题，页面会直接显示原因并定位到字段。

## ② 登录与乘车人

未登录时，在账号区域点击 **“扫码登录 12306”**，用 12306 App 扫码并在手机上确认。本页会显示二维码有效期；过期后可刷新。底部可以返回上一步，登录成功后显示“下一步：确认任务”；扫码入口与步骤导航分开。

登录成功后，页面显示已登录，并在同一区域加载联系人。直接勾选乘车人，最多 5 人，按勾选先后保留顺序。每个人可选择默认、成人票或学生票；默认按 12306 乘客信息购买。尚未确认联系人类型时显示“默认（按12306乘客信息）”，已读取成人或学生身份时分别显示“默认（12306：成人票）”或“默认（12306：学生票）”。学生联系人可以购买成人票；非学生联系人不能仅通过切换车票类型获得学生资格，实际资格仍由 12306 审核。

也可以使用手动填写姓名入口。多个姓名支持英文或中文逗号、顿号、英文或中文分号、换行和制表符；姓名必须与账号中的联系人完全一致。重复姓名和同名联系人歧义会明确提示，不会默选其中一人。

联系人读取失败时，**已登录状态会保留**。可点击“重新读取”，或手动填写姓名。“重新读取”只读取数据，不会触发订票；若会话已失效，页面会提示回到扫码登录状态。

选人完成后，核对显示的人数与车票类型，点击 **“下一步：确认任务”**。此时仍未开始查票或下单。

准备页没有单独的“检查登录状态”按钮，直接登录即可；等待开售期间可在运行页检查会话。检查结果带有时间，网络错误会显示“检查失败”，不会等同于登录失效。

## ③ 确认任务

核对行程、日期、开售时间、车次范围、席别顺序、乘车人、车票类型和任务模式。发现问题可返回前面的步骤修改，草稿会保留。

人数确定后，可在本页设置座位关系、上中下铺数量及静音车厢偏好：

- 座位、铺位偏好只作用于适用席别；取消对应席别后，已填偏好会保留为“未启用”，重新选择该席别后恢复校验。
- 启用的座位或铺位数量需要与乘车人数一致，返回修改人数后请重新核对。
- 静音偏好默认关闭，仅在二等座订单且服务端明确支持时尝试；全部同行乘车人均须遵守静音要求。
- 位置和静音均是偏好，不保证分配成功；程序不会为换位置或车厢自动取消重订。

点击 **“开始任务”** 后，程序执行完整检查并进入第 ④ 页。确认页已承担最终确认作用，不再重复弹出同一份摘要。若存在错误，会返回错误所属页面和字段。

## ④ 等待结果

运行页显示任务真实状态：正在准备、等待开售、查票中、提交中、排队中及最终结果。大号倒计时、查询指标和运行时间线只在此处显示。详细日志继续显示在窗口底部，错误摘要和结果保持可见。

| 页面状态 | 接下来怎么做 |
| --- | --- |
| 等待开售、查票中或提交中 | 保持程序运行，按需查看详细日志。 |
| 当前任务等待重新登录，扫码后自动继续 | 在本页扫描恢复二维码并确认；无需再点击“开始任务”。二维码过期可刷新，也可停止。 |
| 任务已停止 | 需要修改时返回确认页；无需修改时可点击“继续任务”，从 0 开始新一轮查询。 |
| 订单成功 | 点击“前往 12306 支付”，在官方 App 或官网核对待支付订单并完成支付。 |
| 订单状态无法确认 | 先到官方订单页核对，避免直接重复提交。 |

“停止任务”会取消后续操作，但可能需要等待当前网络请求结束。第 ④ 页点击“上一步”也会立即请求停止，并返回第 ③ 页；在当前请求结束及后台清理完成前，页面显示停止过程，参数保持只读。停止完成后即可修改，重新执行仍须明确点击“开始任务”。

结果页的“继续任务”使用保留的配置重新创建任务，查询计数从 0 开始，不会从旧查询轮次或旧候选继续。仍有效的会话和上次成功的校时结果可以复用。乘车日期或原停止时间已经过去时需要先修改配置，跨午夜也不会把原停止时间自动顺延到下一天。若订单状态无法确认，应先到 12306 核对，不能把“继续任务”当作确认旧订单是否成功的方式。

程序不会弹出 Windows 系统通知或播放声音，请留意程序窗口。

## 辅助操作与自动维护

“校准时间”位于时间设置和运行页的辅助区域，显示 RTT、时钟偏移和校准时间。空闲与等待时可用，登录、查票和下单时停用；校时或检查执行中会防止重复操作。校时失败保留上次成功结果，准备时校时不会开始任务。

定时任务通常在开售前 3 分钟复查登录、前 1 分钟最终校时；已有热身安排、较晚登录时的补校时和长热身边界规则保持不变。等待中明确发现登录失效时，任务暂停并要求重新扫码；扫码成功后重新匹配乘车人，继续原任务。手动检查遇到网络错误时会保留原等待状态；自动复查失败则结束任务并说明原因。

## 配置与本地数据

保存格式保持 JSON version 4，并继续读取 v1、v2、v3 和 v4。配置只保存可编辑参数，不保存向导进度、登录状态、Cookie、二维码、Token、证件号码或手机号。每次重新打开程序均需重新登录；同次运行可复用仍有效的会话。

应用版本为 **2.0.0**。命令行入口与订票策略不因四步界面调整而改变。Windows 便携版使用时必须保留 EXE 旁的整个 `_internal` 文件夹。
