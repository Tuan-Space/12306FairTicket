# v2.1.0 发布验证

日期：2026-09-29。应用、Windows 文件版本与产品版本均为 **2.1.0**，GUI 配置为 **JSON v5**。

## 清理范围

- GUI 仅支持 v5；CLI 必须使用 `CART_ITEMS`。已移除 v1–v4 迁移、旧单站执行与排序策略、`CHOOSE_SEATS` 输入、未使用的包装和兼容别名。
- 当前配置保存只包含有效设置，未解决的历史范围信息明确拒绝；旧输入不会扩大购票范围。
- 有效测试改用当前接口；保留登录、联系人、偏好隔离、停止继续、跨夜经停日期及未知订单保护。
- README 保留核心功能、四步流程、四张 2.1.0 实际界面截图和下载说明。更新记录独立维护。
- 历史预览包、阶段报告、额外截图和生成缓存不属于发布源码；用户配置、Git 历史及既有 GitHub Release 不在清理范围。

## 干净环境验证

仅复制待发布源码文件到独立目录，在新建 Python **3.12.12** 虚拟环境中从声明的 `requirements/dev.txt` 安装依赖；未复制原环境的 site-packages。`pip check` 通过，PySide6 **6.8.3**，PyInstaller **6.22.2**。

完整模拟套件共 **1023 项测试、13 项子测试**。首次执行 953 项通过；70 项因测试夹具仍引用已移除的参数或控件而失败。迁移这些夹具后，相关六份测试文件 **178 项、13 项子测试全部通过**，未恢复旧接口；完整套件的全部用例均已覆盖通过。

| 检查 | 结果 |

| 购物车与查询 | 交错顺序、同站对复用、每轮去重、失败重试、整体限速通过 |

## Windows 构建

- 在上述干净源码目录与新环境中重新构建，冻结程序启动自检成功，包含 Qt 图标、二维码与离线 TLS 检查。
- 对照发布源码逐一比较 **29 个内嵌业务模块、GUI 入口和 9 个程序资源**，全部一致；仅忽略环境相关的 Python 源路径。
- 不收集 PDF 与虚拟键盘插件，相关 QtPdf／VirtualKeyboard／Qml／Quick 专用库不再进入包；保留 Windows 平台、系统输入法、SVG、TLS、证书及运行库。
- 用户文档按清单收集，不复制开发报告、测试输出或旧预览文档。许可证文本单独收集。
- 便携包包含 EXE 和 `_internal`，发行 ZIP 的 SHA256 见同一 Release 的 `SHA256SUMS.txt`。

## 复现与发布文件

参见 [开发指南](开发指南.md)。源码通过 GitHub `v2.1.0` 标签对应的 Source code 下载；Windows 包为 `12306FairTicket-2.1.0-windows-x64.zip`。

发布核对采用：Git 标签与 main 提交一致、重新下载源码逐文件比较 Git 对象、重新下载两个 Release 附件比较 SHA256、检查 ZIP 清单及 CRC。依赖锁定保证可按声明环境重建；不同系统或构建时间不保证生成相同 EXE 字节。
