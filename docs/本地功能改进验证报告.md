## 登录、校时和操作方式

README 保留醒目的 **调参数 → 开始任务 → 扫二维码 → 等待** 流程，没有增加版本更新说明。详细操作见 [GUI 使用说明](../README_GUI.md)。

1. 在“运行状态与扫码登录”区域点击“检查登录状态”或“校准时间”，无需先填写完整行程。检查不触发查票、订单或自动扫码。
2. 空闲时使用“扫码登录”独立认证；“从 12306 选择…”可在认证后读取乘车人。等待任务内重新扫码继续原定时任务，重新匹配联系人并生成提交字符串。
3. 通常在开售前 3 分钟复查登录、前 1 分钟最终校时。较长热身时按方案中的 `H/L/S` 公式提前安排；迟登录完成后补校时，避免紧接着重复复查。
4. 手动检查遇到网络或异常格式保留已有会话；定时复查无法确认则结束任务并提示重启。明确失效后等待扫码，二维码过期保持暂停。
5. 额外校时有 10 秒采样预算，请求超时受剩余预算约束。同次应用运行中保留上次成功时钟，覆盖空闲操作、停止后重启及下一次任务；首次校时失败才回退本地时间。

所有会话操作使用同一个工作线程槽串行执行，检查、校时期间防重复点击，查票和下单期间禁用手动维护。系统通知与声音保持关闭，程序内结果反馈保留。
